# About This Portfolio

This portfolio presents technical writing built around the SpaceRisk Radar
application. Its purpose is to explain space technology concepts and document
the verified behavior of a working software project in language useful to
students, developers, technical writers, and engineering recruiters.

## Scope

The collection has two complementary strands:

- **Educational articles** explain TLE data, SGP4 propagation, conjunction
  screening, and orbital debris.
- **Engineering documentation** traces the application's architecture, data
  flow, API, setup, dashboard workflows, and troubleshooting.

The original application repository remains the source of implementation
evidence. This portfolio is a separate documentation repository and does not
replace or edit the application's README.

## Editorial approach

Technical claims are checked against source files where practical. The writing
distinguishes scientific concepts from application behavior and labels
heuristics, approximations, and unverified operational behavior clearly.
References are linked near the concepts they support. API examples describe
actual response shapes with explicitly illustrative values.

The application is an educational monitoring and visualization project. This
portfolio does not claim that it is an operational space-situational-awareness
service, a validated collision probability tool, or a source of maneuver
guidance. See the limitations in the [conjunction-screening article](articles/conjunction-screening.md)
and [debris article](articles/space-debris-and-kessler-syndrome.md).

## About the author

I created this documentation collection to demonstrate how I research,
structure, and explain a technical system. The writing focuses on clear
engineering communication and traceable claims; it does not assert employment,
research partnerships, users, or professional credentials.
